# omni-equations changelog

## 0.1.0 (2026-10-17)
First public release (pre-alpha, stage about 70 %). 67 concepts as dependency-free Rust (`emit/`), their definitions (`emit/index.json`), 39 laws (`laws/`), recorded spec rows
(`specs/`), the standalone checks (`tools/`), the 2026-10-16 logs (`results/`) and the suite (`suite.json`, `install.sh`). The factory that produced them is math-core.
Known gaps: 28 concepts are not re-verifiable from this repository (`STATUS.md`).
