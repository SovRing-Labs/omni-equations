# PROVENANCE — omni-equations 0.1.0

- **Origin.** The 67 concept files were emitted by the SovRing-Labs clean-room factory (repository math-core) between 2026-10-07 and 2026-10-16, each from a published
  definition. This repository is the library part of that work: the emitted Rust, the equations they came from, the laws and the recorded rows.
- **Sources of ideas (no code taken).** Euclid; Montgomery 1985; Posch and Posch 1995; Garner 1959; Wang 1981; Miller 1976; Rabin 1980; Pollard 1975; Brent 1980; Harvey 2012;
  NIST FIPS 203; Ma et al. 2024; the VP9 bitstream specification v0.6; IETF RFC 6716. The emitted Rust was generated from equations authored from behaviour and the published
  definitions; no reference implementation's code is in any file.
- **Third-party code.** None. No file is copied from another project; ScanCode on the release tree finds only Apache-2.0 / CC BY 4.0 text (census record kept by the publisher).
- **AI assistance.** Equations, code and text were written with AI coding assistants (Claude) directed and reviewed by the author; every number in this repository comes from
  a check in `tools/` with its log in `results/`, or from a recorded result file named beside it.
- **Export.** This repository is a fresh single-history export of the development tree (history squashed because the development history carries private paths), cut by a
  manifest-driven release tool that rejects private paths, secrets and databases. The 239 MB of compiled binaries are not part of it (`DATA.md`).
